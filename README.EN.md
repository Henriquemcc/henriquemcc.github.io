# Search Engine Optimization

In this repository there are hosted the following files aiming the optimization of the search of this website through the main search engines:

- [robots.txt](robots.txt): On this file I inform the search engines the pages and the sitemap of this website.
- [_config.yml](_config.yml): On this file I configure jekyll to generate the sitemap.
- [google4954f43c90c89401.html](google4954f43c90c89401.html): On this file I inform my ownership of this website to Google Search Console.
