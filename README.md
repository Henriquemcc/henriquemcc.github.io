# Site Hospedado no GitHub

Este repositório contém o código-fonte do meu site hospedado no GitHub.

## Tecnologias Utilizadas

As principais tecnologias utilizadas são:

- HTML
- CSS
- JavaScript
- Jekyll

## Páginas Hospedadas

### Portfólio

Nesta página são mostrados as tecnologias às quais tenho fluência, além dos projetos aos quais desenvolvi.

Esta página pode ser acessada através do seguinte link: https://henriquemcc.github.io/portfolio

### Linktree

Nesta página disponibilizo os meus links pessoais no formato similar ao linktree. Nela contém os links para as minhas principais contas em plataformas de rede sociais.

Esta página pode ser acessada através do seguinte link: https://henriquemcc.github.io/linktree

## Otimização para Mecanismos de Busca

Neste repositório estão hospedados os seguintes arquivos visando a otimizar a busca deste site pelos principais motores de busca:

- [robots.txt](robots.txt): Neste arquivo, informo aos mecanismos de busca as páginas do site e o mapa do site.
- [_config.yml](_config.yml): Neste arquivo, configuro o jekyll para gerar o mapa do site.
- [google4954f43c90c89401.html](google4954f43c90c89401.html): Neste arquivo, informo a propriedade deste site ao Google Search Console.
